# 🎵 Spotify Clone - Backend

A RESTful backend service for a Spotify clone with Role-Based Access Control (RBAC), enabling Artists to publish music/albums and Users to stream and explore content.

---

## 🌟 Key Features

### 🔐 Authentication & Access Control
* **Dual Role System:** Distinct registration and login workflows for **Users** and **Artists**.
* **Role-Based Access Control (RBAC):** Restricts media creation routes exclusively to verified Artist accounts.

### 🎧 User Features
* **Music & Album Streaming:** Browse and listen to songs and albums published across the platform.
* **Content Discovery:** Access catalog data provided by active artists.

### 🎤 Artist Management
* **Content Creation:** Upload and manage songs, tracks, and album collections.
* **Album Publishing:** Organize single tracks into dedicated albums.

---

## 🛠️ Tech Stack

* **Runtime Environment:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB
* **API Testing & Documentation:** Postman
